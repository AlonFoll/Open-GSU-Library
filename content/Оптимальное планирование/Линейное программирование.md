Задача ЛП в стандартной форме выглядит так:

· Найти: x₁, x₂, ..., xₙ
· Что максимизирует целевую функцию: Z = c₁x₁ + c₂x₂ + ... + cₙxₙ → max
· При ограничениях:
· a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ ≤ b₁
· a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ ≤ b₂
· ...
· aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ ≤ bₘ
· x₁ ≥ 0, x₂ ≥ 0, ..., xₙ ≥ 0 (условие неотрицательности)

Где:

· Z — целевая функция (например, общая прибыль).
· cⱼ — прибыль (или затраты) на единицу продукции j.
· aᵢⱼ — норма расхода ресурса i на производство единицы продукции j.
· bᵢ — доступное количество ресурса i.

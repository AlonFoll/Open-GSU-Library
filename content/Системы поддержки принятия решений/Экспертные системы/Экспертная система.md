Экспертная система - программный комплекс, программно-аппаратный комплекс или устройство, которые используются при решении задач, трудоемких для человека.

Типы:

1. Предоставляют знания
2. Машиннообучаемые системы. Автоматически расширяемые и улучшающие свои базы данных

Отличия от СППР

| 📌 Характеристика        | 🧠 Экспертная система (ЭС)                        | <nobr>📊 Система поддержки </nobr> принятия решений (СППР)   |
| ------------------------ | ------------------------------------------------- | ---------------------------------------------------- |
| Цель                     | Имитация мышления эксперта                        | Поддержка пользователя в выборе оптимального решения |
| Основа                   | База знаний + механизм логического вывода         | Модели, алгоритмы, базы данных                       |
| Тип знаний               | Факты, правила, эвристики                         | Статистика, аналитика, прогнозы                      |
| Роль пользователя        | Получает готовое решение или объяснение           | Активно участвует в анализе и выборе                 |
| Область применения       | Узкоспециализированные задачи (медицина, техника) | Бизнес, финансы, логистика, управление               |
| Пример задачи            | Диагностика болезни, выявление неисправности      | Выбор стратегии продаж, оценка рисков                |
| Интерфейс взаимодействия | Диалоговый, часто с объяснением решений           | Графики, таблицы, сценарии, симуляции                |
| Автономность             | Может работать без участия пользователя           | Требует участия и интерпретации                      |
Экспертные системы - не подержены предубеждениям.

Ограничения:

1. Большинство непригодны для применения конечным пользователем. Доступны только экспертам.
2. Экспертные системы очень трудоемки в разработке.

Состав Экспертной системы:

- база данных
- инструмент доступа

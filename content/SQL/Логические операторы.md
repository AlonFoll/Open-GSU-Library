Каждый логический оператор возвращает булевое (логическое) значение: TRUE или FALSE

- Операторы сравнения

| Оператор | Название | Описание                           |
|----------|----------|------------------------------------|
| \>       | Больше   | значение слева больше чем справа   |
| <        | Меньше   | значение слева меньше чем справа   |
| =        | Равно    | значения слева и справа равны      |
| !=, <>   | Не равно | значения слева и справа отличаются |

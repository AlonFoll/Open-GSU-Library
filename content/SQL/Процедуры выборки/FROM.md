Подключает необходимую для выборки таблицу

```sql
SELECT *
FROM table
```

Часто возникает ситуация, когда данные разбросаны по нескольким таблицам, в меру их нормализации. В таком случае необходимо применение ключевого слова `JOIN`, которое позволяет подключать дополнительные таблице к самой первой.

$BP = CA + KA + FA + \Delta R$

где:

- ( $BP$ ) — платёжный баланс;
  - ( $CA$ ) — текущий счёт (Current Account);
  - ( $KA$ ) — счёт капиталов (Capital Account);
  - ( $FA$ ) — финансовый счёт (Financial Account);
  - ( $\Delta R$ ) — изменение резервов.

2. **Текущий счёт (Current Account)**:

$CA = NX + NY + NCT$

где:

- ( $NX$ ) — чистый экспорт (Net Exports);
- ( $NY$ ) — чистый доход (Net Income);
- ( $NCT$ ) — чистые текущие трансферты (Net Current Transfers).

3. **Финансовый счёт (Financial Account)**:
   $FA = NFDI + NPI + Delta ROR$

   где:

   - ( $NFDI$ ) — чистые прямые иностранные инвестиции (Net Foreign Direct Investment);
   - ( $NPI$ ) — чистые портфельные инвестиции (Net Portfolio Investment);
   - ( $\Delta ROR$ ) — изменение в остальных резервных активах (Changes in Other Reserve Assets).
